# ECHO NANO CFW 生成アプリ（非公式・ベータ版）

SNOWSKY ECHO NANO の公式ファームウェア V2.0.0 を元に、操作の割り当て・日本語フォント・起動画面などを変えたカスタムファームウェア（CFW）を作るブラウザアプリです。

**FiiO／SNOWSKYとは関係のない非公式のツールです。ファームウェアの書き換えは自己責任で行ってください。**

アプリを開く：https://ma2-ma2.github.io/echo-nano-cfw-generator/

## できること

- **操作の割り当て**：ホイールで曲送り・曲戻し、側面ボタンで音量、のように役割を入れ替えます。ホイールの回す向き、側面ボタンの左右もそれぞれ逆にできます。変わるのは再生画面の操作です。
- **日本語フォント**：手元のTTF／OTFフォント（12ドット以下のドットフォント向け）から本体の12ドット字形を作ります。以前にこのアプリで作ったCFWからフォントを取り出すこともできます。
- **画面の差し替え**：電源ON・電源OFF・お気に入り登録時の画面を、用意した画像（128×32ピクセル以内）に替えます。複数の画像やアニメーションGIFでコマ送りにもできます。
- **プレビュー**：本体図で操作を試したり、曲名が本体でどう表示されるか（スクロールを含む）を確かめたりできます。
- 公式のファームウェア・フォント・曲はアプリに含まれていません。すべて手元のファイルを選んで使います。ファイルは外部に送信されず、処理はブラウザの中だけで行います。

## 必要なもの

- パソコン（Mac／Windows）と Google Chrome または Microsoft Edge（Macで動作確認済み。Windowsは未確認）
- 公式ファームウェア V2.0.0 の `NANOV200.IMG`（FiiOの配布ページから入手）：[ECHO NANO 公式ファームウェアと更新手順](https://forum.fiio.com/phoneNote/showNoteContent.do?id=202605161533005115232)
- フォントを変える場合：TTF／OTFのドットフォント（例：JFドット東雲ゴシック12、JFドットM+12、JFドットK12。ライセンスは各配布元で確認してください）

## 使い方

1. アプリを開き、手順1で公式の `NANOV200.IMG` を選びます（ドラッグ＆ドロップも可）。最初に「公式IMGの控えを保存」で控えを取っておくと、元に戻すときに使えます。
2. 手順2で変えたい項目をオンにします。本体プレビューで操作や曲名の表示を確かめられます。
3. 手順3の「CFWを生成」を押し、「IMGを保存」または「更新用コピーを保存先に書き込む」で保存します。
4. 保存したIMGを `NANOV200.IMG` という名前で、本体の内蔵ストレージのルートに1つだけ置きます。パソコンから安全に取り外し、公式の更新手順に従って本体を更新します。

## 元に戻すには

公式の `NANOV200.IMG`（手順1で保存した控え、または公式の配布ファイル）を、同じ手順で本体に置いて更新します。
